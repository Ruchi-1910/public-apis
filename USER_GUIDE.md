# Simple Calculator – User Guide

## 1. Introduction

The Simple Calculator is a basic application designed to perform common mathematical operations. It allows users to enter numbers and perform operations such as addition, subtraction, multiplication, and division.

## 2. Features

* Addition
* Subtraction
* Multiplication
* Division
* Simple and easy-to-use interface
* Fast calculation of results

## 3. System Requirements

| Requirement          | Specification       |
| -------------------- | ------------------- |
| Operating System     | Windows/Linux/macOS |
| Programming Language | Python              |
| Python Version       | Python 3.x          |
| RAM                  | Minimum 2 GB        |
| Browser              | Not required        |

## 4. Installation

Download or clone the application repository and open the project folder.

Install the required dependencies using:

```bash
pip install -r requirements.txt
```

## 5. Running the Application

Run the following command:

```bash
python calculator.py
```

The calculator application will start and allow the user to perform mathematical operations.

## 6. How to Use

1. Start the calculator application.
2. Enter the first number.
3. Select the required mathematical operation.
4. Enter the second number.
5. View the calculated result.
6. Repeat the process for another calculation.

## 7. Example

Suppose the user enters:

```text
First Number: 20
Operation: +
Second Number: 10
```

The application displays:

```text
Result: 30
```
